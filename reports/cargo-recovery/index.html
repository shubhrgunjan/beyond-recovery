How to read this draft

Only runs with a complete manifest, completed full-course summary, explicit baseline eligibility, declared payload/route/deadline, and required source hashes qualify as baseline parents. A fork enters matched outcome counts only when its parent qualifies, frozen source hashes match, the parent model hash matches, a checkpoint digest exists, and both fork summary and manifest are complete. An ineligible continuation is archived as engineering context and does not enter the matched recovery bank.

Inputs are read-only. The JSON file beside this report includes generated time, input paths and hashes, per-run inclusion reasons, source hashes, optional campaign status, raw outcomes, and aggregate counts. Regenerate after new cases complete to refresh the evidence.
