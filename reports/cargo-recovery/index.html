Does standing and task progress diverge?

For each eligible disturbed fork this report records task resumption separately from eventual placement completion. A case with resumption but no placement, or placement without a recorded resumption event, is flagged as a divergence. There are no eligible disturbed forks yet, so this question is still open. Zero-force controls are not counted as recovery cases.

Course and constraints

Evidence boundary

  • Native MuJoCo G1 model and finite-rate policy inference.
  • Privileged-state IK plans arm motion; gripper contacts and crate motion remain simulated physics.
  • No VLA control, perception-driven navigation, physical hardware, thermal/audio sensing, or heavy-box manipulation.

Failure labels

  • Fall: mission controller’s declared fall outcome.
  • Drop: mission controller’s declared payload-drop outcome.
  • Timeout: original task deadline reached; does not imply permanent inability.
  • Placement failure: placement verification ended without qualified placement.
  • Technical: runner/export/infrastructure issue; excluded from behavior counts and kept in the data file.

How to read this draft

Only runs with a complete manifest, completed full-course summary, explicit baseline eligibility, declared payload/route/deadline, and required source hashes qualify as baseline parents. A fork enters matched outcome counts only when its parent qualifies, frozen source hashes match, the parent model hash matches, a checkpoint digest exists, and both fork summary and manifest are complete. An ineligible continuation is archived as engineering context and does not enter the matched recovery bank.

Inputs are read-only. The JSON file beside this report includes generated time, input paths and hashes, per-run inclusion reasons, source hashes, optional campaign status, raw outcomes, and aggregate counts. Regenerate after new cases complete to refresh the evidence.

Not a claim about general or physical robot recoverability. This report does not claim a research gap from the earlier locomotion qualification study.
